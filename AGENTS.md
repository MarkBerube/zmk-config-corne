# Working on the Corne

Use this repository for Mark’s Advantage2-style keymap and the firmware delivered to the keyboard. Start with the [repository guide](README.md) for file ownership, artifact selection, and the hardware checks.

For artwork changes, edit the linked display module first and update the `corne-display-art` revision here. When sharing firmware, link the successful run for the intended commit in **MarkBerube/zmk-config-corne** and identify the half to flash.
